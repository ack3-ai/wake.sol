# Shared ack3 Git policy

The canonical Git and agent workflow is maintained once in
[`ack3-workspace/CONTRIBUTING.md`](https://github.com/ack3-ai/ack3-workspace/blob/main/CONTRIBUTING.md).

Before modifying files or Git state, read the current canonical policy. In the
standard ack3 workspace checkout, it is available at `../CONTRIBUTING.md`;
otherwise use the link above. Repository-specific `AGENTS.md` and `CLAUDE.md`
instructions also apply and take precedence when stricter.

This file is intentionally only a stable pointer. Do not copy the shared policy
body back into this repository.
